## Usage Guidelines

- Use primary colors for interactive elements and brand consistency
- Apply status colors to communicate state (success, warning, info, danger)
- Use neutral grays for backgrounds, text, and borders
- Maintain sufficient contrast for accessibility (WCAG AA minimum)
- Never use hardcoded hex values in components; use Tailwind theme tokens
